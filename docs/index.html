Liquidity-gate ablation (original contribution). The 113-name universe carries zero zombie contamination — the thinnest name in the low-vol quintile trades >$5M/day, so an absolute floor ($0.1M-$5M) never binds in backtest and is kept purely as a live-deployment guard. The relative median gate is the opposite of a drag: it is the only configuration whose OS>IS across both daily and weekly rebalancing (OS 1.67 / 1.55). Removing the gate yields OS 2.33 on daily rebalancing but collapses to 0.19 on weekly — frequency-fragile, therefore rejected. The gate buys robustness, not return.
