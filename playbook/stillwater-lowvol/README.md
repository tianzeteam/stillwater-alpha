# Stillwater Low-Vol Rotation (rTokens)

静水 · Stillwater — 在流动性达标的 Bitget rToken（代币化美股）中，每周轮动持有近期波动最低的一小篮子标的，等权持有，不加杠杆、不做空。

## 策略 / Strategy

市场在散户主导的环境里，注意力永远追着昨天涨得最猛的东西跑。本策略反其道而行：它只关心"谁最安静"。每个候选池中的 rToken 都会按其近期实际波动率排序，同时用流动性筛（成交额是否达到池内中位水平）过滤掉那些看似安静、其实是"僵尸标的"的名字——价格长期不动不代表安全，可能只是没人交易。只有同时满足"波动足够低 + 流动性足够好"的标的，才有资格进入当期组合。

## 开仓 / Entry

每周一次调仓。在满足流动性门槛的候选标的中，选取近期波动率最低的若干只（数量由参数控制），等权买入。若某只标的已持有且仍在选中名单里，则保持不动；若是新入选标的，则用配置的预算按等权比例买入。整个组合始终是纯多头现货持仓。

## 平仓 / Exit

没有止损线，也没有止盈线——风险管理完全依赖"每周重新筛选"这个动作本身。当已持仓标的的波动率上升到不再属于最安静的一组，或其流动性滑落到组合标准以下，它会在下一次周度调仓时被卖出，资金轮动到当期符合条件的新名单。市场恐慌时所有标的会一起下跌，此时组合会照常持有筛选后的结果。

## 风险 / Risk

最大的风险是系统性风险：在代币化股票整体崩盘时，"最安静"的标的照样下跌，本策略跑不赢空仓。在由高波动标的驱动的狂热牛市里，它也会明显跑输——这本质上是一个"睡得着"的策略，不是"暴富"策略。其他风险包括：个别 rToken 上市/退市带来的数据中断、周末与闭市时段的价差扩大、以及代币化股票特有的赎回机制影响。历史回测结果不保证未来收益，请把它当作保守的核心配置，并用自己的风险承受能力校准参数。

## 用户可调参数 / Tunables

- **Candidate rTokens**：候选池。扩大候选池分散更多风险，但增加数据负载；缩小则组合更集中于你挑选的标的。
- **Names held per rebalance**：每次持有几只。持有更少 → 更集中于稳定；持有更多 → 更分散但稀释低波倾向。
- **Margin budget USDT**：平台下单与收益百分比计算所用的本金基数。
